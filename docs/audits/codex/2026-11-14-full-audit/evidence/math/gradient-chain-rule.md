# Проверка производной по весу

Для нейрона `z = Σ(wᵢ × aᵢ) + b` производная ошибки по весу равна:

`∂L/∂wᵢ = (∂L/∂z) × aᵢ`.

При шаге SGD `w_new = w_old − η × ∂L/∂w` производная по весу восстанавливается как `(w_old − w_new) / η`. Именно с ней сравнивается конечная разность ошибки при изменении этого веса. Делить дополнительно на активацию нельзя: получится производная по z, другая величина.

Конкретный пример: сеть `[2,3,2]`, seed 7, вход `[0.2,0.8]`, правильный класс 1, параметр `layers[1].weights[0]`, η=1.

| Величина | Значение |
| --- | ---: |
| Активация предыдущего нейрона | 0.2725503742694855 |
| ∂L/∂z | 0.5545456409454346 |
| ∂L/∂z × a | 0.1511416219891899 |
| Конечная разность ∂L/∂w | 0.1511416131860530 |
| (w_old − w_new) / η | 0.1511416211724281 |
| Ошибка восстановления ∂L/∂w | 7.99e−9 |
| Неверное дополнительное деление на a | 0.5545456379486976 |

Повтор исходного численного прохода воспроизвёл все девять сводок для 13 506 параметров: расхождение не более `9.353394e−8`, превышений допуска `2e−6` нет. Это проверка указанных конфигураций и численных диапазонов, а не доказательство корректности на любых экстремальных значениях.

Исходный модуль и штатный тест не менялись. [Конфигурация, результаты и хеши](gradient-chain-rule.json). Основной воспроизводимый скрипт: [math-probes.mjs](math-probes.mjs); в нём конечная разность вычисляется независимой реализацией прямого прохода.
