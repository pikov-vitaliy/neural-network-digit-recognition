# Предварительный просмотр учебной лаборатории

Статус: ознакомление с незавершённой реализацией. Итоговая приёмка не проводилась.

Проект: `neural-network-digit-recognition`. Курс: «Искусственный интеллект для инженеров». Дата: 14 ноября 2026 года, Europe/Amsterdam. Точное время чтения файлов приведено в [evidence.md](evidence.md).

## Требования и границы просмотра

Пользователь поручил посмотреть текущую работу разработчика, а полную проверку выполнить после его сообщения о завершении. Подтверждено изменение размера изображений с 36×36 на **16×16**, чтобы элементы сети были лучше видны. При последующей приёмке действует размер 16×16.

В ходе просмотра прочитаны проектное описание, настройки пакета, отдельные участки вычислительного кода и состав файлов. Посчитаны примеры и прочитаны размеры из заголовков PNG. Приложение, обучение, тесты и установка через npx не запускались. Исходники приложения не изменялись.

## Вывод по текущему этапу

В проекте уже есть вычислительное ядро, набор примеров и файлы интерфейса. По этому просмотру нельзя заключить, что приложение готово к занятию или установке студентами. Отсутствующие на данном этапе файлы не оформляются как дефекты завершённой версии.

Полная проверка начнётся после сообщения разработчика о завершении. Перед ней нужно заново зафиксировать состояние файлов: разработка продолжается, этот срез может устареть.

[Перечень будущих проверок](acceptance-checklist.md) отделяет требования задания от дополнительных проверок надёжности.
