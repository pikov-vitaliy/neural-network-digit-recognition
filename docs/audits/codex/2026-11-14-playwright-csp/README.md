## Почему исправление подходит

Запрет применяет браузер по политике, установленной сервером. В `src/server.js:25` задано `script-src 'self' 'unsafe-inline'`, без `unsafe-eval`. Разрешение встроенных скриптов не разрешает компиляцию строк через eval. Это согласуется с [CSP Level 3](https://www.w3.org/TR/CSP3/#can-compile-strings).

В [текущей ветке main Playwright](https://github.com/microsoft/playwright/blob/main/packages/playwright-core/src/server/frames.ts#L1477-L1503) ожидание функции использует `globalThis.eval(expression)`. Эта ссылка объясняет механизм, но не устанавливает точную локальную версию.

[`to_have_text`](https://playwright.dev/python/docs/api/class-locatorassertions#locator-assertions-to-have-text) проверяет текст найденного элемента с повторными попытками. Для ожидания имени выбранного файла это прямое выражение проверяемого условия.
