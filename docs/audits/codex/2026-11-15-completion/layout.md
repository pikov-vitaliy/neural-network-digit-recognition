# Конечная раскладка и снимки для README

15 ноября 2026 года. Проверена интегрированная версия после сужения боковой панели CNN и переноса управления эпохами наверх. Код приложения в этом этапе не изменялся.

## Результаты

- Все 12 сочетаний MLP/CNN, светлая/тёмная тема и 1280×720, 1366×768, 390×844 прошли проверку. Горизонтального переполнения нет, ошибок страницы нет. Доказательство: `final-ui-delivery.json` и `final-{mlp,cnn}-{light,dark}-{1280,1366,390}.png`.
- Клавиатурный фокус виден в обеих темах. На полях скорости подтверждены `:focus-visible`, сплошной контур 3 CSS px, контрастные цвета темы. В светлой теме цвет контура `rgb(184,101,25)`, в тёмной `rgb(247,178,103)`.
- Реальный масштаб браузера 200% проверен через Page zoom в настройках отдельного временного профиля Chromium. При неизменном внешнем окне 1366×900 получено 675×402 CSS px и DPR=2. В обоих примерах ширина документа 667 CSS px; горизонтального переполнения нет. Инспектор MLP и окно CNN доступны по штатным ссылкам, поля и текст не перекрываются. Обычный профиль пользователя не изменялся.
- Для масштаба 200% стандартный Playwright screenshot дал пустое изображение из-за захвата с неверным масштабом. Такие кадры `final-*-zoom200.png` не служат визуальным доказательством. Корректные кадры получены напрямую через CDP `Page.captureScreenshot`: **`final-mlp-zoom200-native.png` и `final-cnn-zoom200-native.png`**. Они просмотрены. Положение реальных элементов дополнительно записано в `zoom-final-visual.json`; воспроизведение в `zoom-final-visual.cjs`. Основной сценарий также исправлен для будущих запусков.

## README

Сохранены два снимка viewport 1600×1120, без личных путей, временных уведомлений и незавершённых переходов полос вероятности:

- `docs/screenshots/mlp.png`: обученная за 960 шагов MLP, пример цифры 5, ответ 5, доля softmax 89,4%, видны схема и инспектор.
- `docs/screenshots/cnn.png`: обученная за 960 шагов CNN, тот же пример 5, ответ 5, доля softmax округлена до 100,0%. Показаны окно 3×3, карта фильтра 4, позиция [8,8] и крупные значения суммы, смещения, z и ReLU. Это снимок одного примера, а не заявление о качестве на всём наборе.

Снимки созданы штатными действиями интерфейса. Ни значения модели, ни изображения, ни подписи в приложении для снимка не подменялись. Выбрана ячейка с ненулевой активацией, показ остановлен. Скрипт: `readme-screenshots.cjs`, числа и геометрия: `readme-screenshots.json`.
