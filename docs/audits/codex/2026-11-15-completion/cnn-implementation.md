# Численные правила CNN

Второй пример использует Float64. Вход 16×16×1 проходит свёртку 3×3 с 8 фильтрами, ReLU, pooling 2×2, свёртку 3×3 с 16 фильтрами, ReLU и второй pooling. Результаты имеют формы 16×16×8, 8×8×8, 8×8×16 и 4×4×16. Разворачивание даёт 256 значений; полносвязный слой имеет 10 выходов softmax.

Параметры: (3×3×1+1)×8 + (3×3×8+1)×16 + (256+1)×10 = 3 818. Из них 3 784 веса и 34 смещения.

Индекс тензора HWC равен (y×W+x)×C+c. Индекс веса свёртки равен ((filter×Cin+channel)×3+ky)×3+kx. Вес полносвязного выхода имеет индекс classId×256+source. Выполняется cross-correlation без переворота ядра, шаг 1, нулевое дополнение 1. Производная ReLU в нуле принята равной нулю. Pooling имеет окно и шаг 2; при равных максимумах выбирается первая позиция в порядке слева направо, сверху вниз. Обратный проход использует тот же выбор.

Начальные параметры детерминированы seed 20261114. Шаг SGD по умолчанию 0,03. Проверены значения 0,01, 0,03 и 0,05 на трёх seed; выбор сделан по validation. Результат не считается независимой test-оценкой.

Каждый forward содержит снимок входа, параметров и промежуточных тензоров. Подготовка шага ничего не меняет. Применение проверяет владельца плана, версию шагов и конечность новых значений, затем атомарно заменяет параметры. Один план применяется один раз. Для общего веса фильтра dL/dw суммирует вклады всех пространственных позиций; интерфейс раскрывает эту сумму. У полносвязного веса один вклад.

Формат JSON: version 1, kind cnn16, seed, steps и три блока parameters. Он отличается от MLP и хранится под отдельным ключом. Импорт проверяет тип, формы, безопасный счётчик и численные границы до изменения модели. Внешний экспорт содержит модель; история эпох хранится отдельно в браузере.

[Проверки ядра](../../../../test/cnn-network.test.js) охватывают свёртки, смещения, dense, формы, снимки, градиенты, ReLU=0, равные максимумы, повторное применение и небезопасный импорт. Все 3 818 производных дополнительно сравнены с центральными конечными разностями с epsilon 10⁻⁶ вне точек негладкости. [Результаты](evidence/math/cnn-verification-final.json).
