# Разбор независимой критики

15 ноября 2026. Выполнены отдельные проверки editor и checker на kimi-code/k3.1-pro, effort high. Оба первых запуска завершены; подтверждены модель и effort. Полные отзывы и краткие статусы находятся в [reviews](reviews/). Эти проверки читали исходники и сохранённые доказательства, не запускали приложение самостоятельно.

| Замечание | Решение и доказательство |
|---|---|
| Editor 1: направление градиента объяснено двусмысленно | Принято. В teacher-view.js явно сказано: градиент указывает рост ошибки, SGD идёт в противоположном направлении. Формула не менялась. |
| Editor 2 / Checker 4: расходятся списки форматов | Принято. Подпись загрузки и сообщения input-controller перечисляют PNG, JPG, WebP, GIF и BMP, как README и accept. |
| Editor 3: лозунг и лишние тире/стрелки в прозе | Принято. Заголовок заменён на «Один шаг и цикл из 12 эпох»; определения и памятка сформулированы прямо. Математические обозначения и значки навигации сохранены по смыслу. |
| Checker 1: промежуточный tarball не соответствует окончательному дереву | Принято. Создан новый release-candidate-1, SHA256 2968c40b4169a4e58a0789d5e5857d5a32f53658c2cbc3b63dd0ed5b3068b4d2. Все 130 файлов совпали с рабочим деревом. Повторены 62 теста на каждой версии Node, offline install и npx с пустым cache. [Сверка](evidence/packaging/final-candidate-seal.json). Публичный registry проверяется отдельно после выпуска. |
| Checker 2: метрики отстают от остановки CNN | Принято. cancelTraining пересчитывает метрики синхронно до статуса остановки. Проверка сохраняет DOM-значения в том же задании JavaScript, до передачи управления таймеру, затем сравнивает их с evaluate. |
| Checker 3: выбранная цифра CNN не выделена | Принято. В распознавании ровно одна строка получает target; выбор нового класса снимает прежнее выделение. Модель неизменна. Проверены все десять классов. |
