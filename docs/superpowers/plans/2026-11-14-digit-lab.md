# Digit Lab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Собрать автономное npx-приложение, которое обучает нейросеть на 100 изображениях 16×16 и наглядно показывает распознавание цифр.

**Architecture:** Браузерный JavaScript без runtime-зависимостей выполняет настоящие forward/backpropagation; Node используется только для генератора, тестов и локального static server. Общие ES-модули из `src/shared/` доступны Node-тестам и браузеру через маршрут `/shared/`.

**Tech Stack:** Node >= 20, `node:test`, `node:http`, `zlib`, vanilla HTML/CSS/JavaScript, Canvas 2D, native dialog, localStorage.

**Spec:** `docs/superpowers/specs/2026-11-14-digit-lab-design.md`

## Global Constraints

- Изображения строго 16×16; архитектура по умолчанию `256 → 16 → 12 → 10`, 4 408 весов связей.
- Ноль обязательных npm-зависимостей, ноль внешних запросов приложения, никакого обязательного build step.
- Публичный запуск после публикации: `npx -y neural-network-digit-recognition`.
- UI и учебные подписи на русском; порядок ответов `[1,2,3,4,5,6,7,8,9,0]`.
- Node >= 20; сервер слушает только `127.0.0.1`, начальный порт 4173.
- Не выполнять git commit, git push, npm publish и создание удалённого репозитория без явной просьбы.
- Каждый программный компонент сначала получает failing test; после реализации запускается весь `npm test`.

## Review Focus

- Светлое/тёмное пользовательское изображение и пустой холст: нормализация не должна выдавать NaN или молча переворачивать цифру — Task 2.
- Повреждённый/чужой JSON модели: импорт обязан отклонить его без разрушения текущей сети — Task 1 и Task 5.
- Занятый порт и повторный запуск: выбрать следующий порт, не открывать браузер в CI/`--no-open` — Task 3.
- Двойной клик по автообучению и сброс во время эпохи: нельзя запускать параллельные циклы или изменять сброшенную сеть — Task 5.
- Маленький экран, клавиатура и reduced motion: панели не перекрываются, controls доступны, анимация отключается — Task 4 и Task 6.

- [ ] **Step 2: Запустить RED.** `node --test test/neural-network.test.js` должен завершиться отсутствующим модулем до реализации.
- [ ] **Step 3: Реализовать минимальный класс.** Xavier/sigmoid/softmax/cross-entropy; сначала вычислить все delta на старых весах, затем обновить слои; сериализация каждого Float32Array в base64 через `btoa/atob`, версия модели 1 и строгая проверка формы.
- [ ] **Step 4: Запустить GREEN.** `node --test test/neural-network.test.js`; затем полный `npm test` после появления скрипта.
