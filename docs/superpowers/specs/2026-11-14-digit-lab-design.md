# Нейросеть для распознавания цифр — проектный дизайн

## Замысел

Интерактивная демонстрация для курса «Искусственный интеллект для инженеров». Преподаватель запускает приложение локально одной командой, обучает настоящую нейросеть на встроенных примерах, а затем показывает распознавание и прохождение сигнала по слоям. Студенты получают тот же пакет через GitHub и npm.

## Цели

- Запуск в PowerShell: `npx -y neural-network-digit-recognition` после публикации пакета; браузер открывается автоматически.
- Полностью локальная работа после установки: никаких внешних API, шрифтов, CDN и серверного обучения.
- Три рабочие области: входное изображение, структура сети, вертикальные ответы `1…9, 0`.
- **100 детерминированно созданных PNG 16×16**: по 10 вариантов каждой цифры, разные начертания, небольшие сдвиги, повороты, толщина и шум. Размер изменён по решению пользователя ради читаемой визуализации.
- Режим обучения с ручной меткой, обучением одного примера и автоматическими эпохами; режим распознавания с уверенностью и активными связями.
- Загрузка своего изображения и рисование цифры мышью или пером.
- Сохранение обученной модели в `localStorage`, экспорт и импорт JSON, сброс модели.
- Понятные объяснения на русском языке и управление с клавиатуры.

## Не входит

- Production-распознавание рукописных документов и обещание качества MNIST.
- Аккаунты, облако, сбор телеметрии, удалённый сервер inference.
- Публикация в npm/GitHub без явной команды владельца.

## Подходы

1. **Чистый JavaScript в браузере — выбран.** Настоящие forward pass, softmax, cross-entropy и backpropagation видны в небольшом исходнике; npm содержит только статические файлы и Node CLI. Нет зависимостей времени выполнения и шага сборки.
2. TensorFlow.js: удобнее для больших моделей, но скрывает учебную математику и добавляет большой пакет.
3. Python/серверное обучение: подходит для ML-курса, но усложняет установку и противоречит запуску через один npm-пакет.

## Архитектура

- `bin/digit-lab.js`: Node CLI, HTTP-сервер только на `127.0.0.1`, безопасная раздача `public/`, открытие браузера, `--port`, `--no-open`, `--help`, `--version`.
- `public/`: HTML, CSS, браузерные модули, 100 PNG и manifest с пикселями и метками.
- `src/shared/neural-network.js`: ES-модуль без DOM, общий для Node-тестов и браузера. Слои **`256 → 16 → 12 → 10`**, sigmoid на скрытых слоях, softmax и cross-entropy на выходе, Xavier-инициализация, SGD.
- `src/shared/image.js`: общая нормализация входа для генератора, загрузки и рисования.
- `scripts/generate-samples.js`: воспроизводимый генератор PNG на встроенном `zlib`; 80 примеров образуют обучающую часть, 20 — проверочную (по 8/2 на цифру).
- `test/`: встроенный `node:test`, включая численную проверку градиентов, сохранение/восстановление и реальное обучение.

## Интерфейс

- Заголовок: название курса, имя лаборатории «Цифра. Слой за слоем», справка, тема.
- Слева: предпросмотр 16×16, встроенные примеры с фильтрами, метка правильного ответа, загрузка и холст для рисования.
- В центре: переключатель «Обучение / Распознавание», метрики, Canvas со **всеми 4 408 связями**. Входной слой показан как настоящая решётка 16×16; скрытые нейроны — кружки с активациями. Все связи остаются видимы фоном, а наиболее значимые для текущего входа подсвечиваются поверх. Наведение объясняет нейрон и связь; выбор нейрона открывает точные входящие веса.
- Справа: десять крупных цифр в порядке `1, 2, …, 9, 0`, полосы softmax и проценты; лучший ответ выделен.
- Нижняя панель: ход эпохи, loss/accuracy и короткая интерпретация текущего шага.
- Диалог «Как объяснить на занятии»: сценарий из пяти шагов и формулы.

## Визуальная система

- Цвета: графит `#0B1220`, панель `#121C2E`, чертёжная линия `#29364B`, сигнал `#82A6FF`, положительный `#66D9C2`, янтарный `#F7B267`; светлая тема использует холодную бумагу `#EEF2F7`.
- Шрифты без сети: `Bahnschrift, Segoe UI, sans-serif` для заголовков и интерфейса, `Cascadia Mono, Consolas, monospace` для чисел.
- Подпись дизайна: импульс по связям, сопровождаемый реальными численными значениями; спокойные панели без лишнего декора.
- Адаптивная сетка: три колонки на широком экране, две на среднем, одна на телефоне; `dvh`, `clamp`, минимальные цели 24 px, `focus-visible`, reduced motion.

## Данные и состояние

- Каждая запись manifest: `id`, `label`, `split`, `file`, `pixels` (base64 из 256 байт 0…255).
- Генератор и inference используют общий `normalizePixels`: автоинверсия при средней яркости рамки > 0,5; отсечение фона на 0,12; bounding box; масштаб длинной стороны до 12 px; размещение по центру масс в 16×16. После нормализации генератор добавляет только малый сдвиг ±1 px и шум.
- Seed генератора: `20261114`; варианты 0…7 каждой цифры — train, 8…9 — validation.
- Сохранение: JSON-обёртка версии 1 с Float32Array в base64, ключ `ai-engineers-digit-lab-model-v1`; несовместимая версия игнорируется с понятным предупреждением. Экспорт/импорт использует ту же проверяемую схему.
- Тема: система по умолчанию, ручной override в `localStorage`, синхронизация `meta[name=color-scheme]` и CSS.

## Детали реализации и проверки

- Сначала failing-тесты, затем реализация.
- Unit: размеры, диапазоны, softmax, детерминизм, численный градиент, сериализация, генерация ровно 100 корректных PNG. PNG проверяются по сигнатуре, IHDR, размерам и соответствию manifest; кросс-версионный byte-for-byte deflate не требуется.
- Метрики: loss — средняя cross-entropy эпохи; accuracy отдельно для train и validation. Интеграционный тест: loss снижается, validation accuracy ≥ 0,6 не более чем за 12 эпох при фиксированных seed; фактический результат будет записан.
- Внутренние индексы классов 0…9 соответствуют цифрам 0…9; UI выводит порядок `[1,2,3,4,5,6,7,8,9,0]`.
- Canvas: статичные линии кэшируются в offscreen Canvas и перестраиваются только при resize/смене темы; поверх рисуются не более 250 связей с наибольшим `abs(weight × activation)`. Выбранная связь показывается отдельно с точным весом.
- CLI: Node >= 20, порт 4173 с автоинкрементом до 10 портов; `CI` или `--no-open` отключают открытие. Windows использует `cmd /c start`, macOS — `open`, Linux — `xdg-open`; `.gitattributes` фиксирует LF для JS и bin.
- CLI-проверка: ответ сервера, MIME, защита путей, завершение, реальный запуск собранного tarball через `npx -y`.
- Браузерную проверку выполняет встроенный браузер Kimi Code: полный сценарий обучение → распознавание → рисование/загрузка → сохранение; консоль без ошибок; скриншоты широкого и узкого экранов. Playwright и другие зависимости не нужны.
- Экспериментальный `canvas-html` не используется: Canvas имеет `role=img`, текстовое описание и семантическую таблицу выходов как альтернативу.

## Принятые решения в auto-режиме

- Имя npm-пакета `neural-network-digit-recognition` выбрано после проверки, что registry вернул 404; владелец должен опубликовать его под своей учётной записью.
- Проект изначально пуст и не является git-репозиторием; создание коммитов и удалённая публикация не выполняются.
- Точные значения всех весов доступны через инспектор, а на общей схеме подписываются только выбранные связи — иначе подписи физически нечитаемы даже при 4 408 соединениях.
